# RepoReady MCP plugin

Always activate the project's conda environment before doing any work here: `conda activate repoready-mcp-plugin` (Python 3.11; the checks need only it and bash). Cloud clones without conda use any Python 3.11.

This repository distributes the RepoReady MCP connection, workflow skill and Claude commands. See README.md for installation and the shared guidance for development.
